   `openpix_observability/server.py` provides `serve(app)` (two-listener
   bootstrap) and `register_probes(app, response_model=, ok_value=)`; all

   `configure_logging()` now runs at import time in all three `main.py`

   main:app` runtime keeps `trace_id`/`correlation_id` on access logs.
   Regression test: `test_structured_logging_active_at_import`.

   all-zero trace-id/span-id per W3C Trace Context; parametrized tests
